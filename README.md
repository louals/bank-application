## Tech Stack

TypeScript, React

## Features

- Account management
- Modern banking interface

## Getting Started

### Prerequisites

Make sure you have the tools required for this stack installed (e.g. Python 3.10+, Node.js 18+, or Android Studio).

### Installation & Usage

```bash
git clone https://github.com/<your-username>/bank-application.git
cd bank-application
npm install
npm run dev     # or `npm start`, depending on the setup
```
